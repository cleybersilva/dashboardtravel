# Monitor de Voos Multi-Destino

Dashboard estático publicado via GitHub Pages. Lê os dados do Supabase
(gravados pelo workflow N8N a cada 1h) e permite adicionar novos destinos
para monitorar, direto pela própria página.

Antes de publicar, confira em `index.html`:
- `SUPABASE_URL` e `SUPABASE_ANON_KEY`
- `SENHA_DESTINO` (senha do formulário "adicionar destino")
